# 🎸 Lyric Page: O Que É o Que É? (Gonzaguinha)

Este repositório apresenta um Web Design responsivo desenvolvido para homenagear a obra-prima de **Gonzaguinha**. O site funciona como uma central de informações sobre a canção, reunindo letra, ficha técnica e elementos interativos em uma interface moderna e intuitiva.

## 🛠️ Pilares Tecnológicos

A construção da página foi baseada em tecnologias front-end de alto desempenho:

**Estrutura:** HTML5 para organização semântica.
**Estilização & Layout:** [Bootstrap 5.3](https://getbootstrap.com/), utilizando o sistema de containers e grid para garantir que o site funcione em qualquer resolução.
**Iconografia:** Bootstrap Icons, trazendo indicadores visuais para as seções de menu e cards.
**Dinamismo:** Bundle JS do Bootstrap para gerenciamento de componentes como o Carrossel de fotos e o Modal de contato.

## 🌟 Destaques do Projeto

O layout foi planejado para oferecer uma navegação fluida:

**Interface Adaptável:** Graças ao uso de classes utilitárias do Bootstrap, a página é totalmente Mobile-First.
**Galeria de Imagens:** Implementação de um Carrossel (Slider) que percorre registros visuais do artista.
**Experiência do Usuário (UX):** Uso de Alerts fecháveis para boas-vindas e um Modal elegante para o formulário de contato, evitando recarregamentos desnecessários da página.
**Curadoria de Conteúdo:** Separação visual entre a letra da música, a biografia resumida e a discografia sugerida na barra lateral.

## 📂 Execução Local

Para visualizar este projeto em sua máquina:

1.  Faça o download do código fonte.
2.  Mantenha os arquivos de imagem (.jpg ou .webp) no mesmo diretório do arquivo principal.
3.  Execute o arquivo no navegador (não é necessário servidor local, pois as bibliotecas são carregadas via CDN).

## 🎶 Contexto Cultural
O projeto celebra a **MPB (Música Popular Brasileira)**, focando na poesia existencialista de Gonzaguinha que questiona: "E a vida? E a vida, o que é?".
